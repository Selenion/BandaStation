# Поведение BandaStation, обязательное для переноса атмоса

Эталон: BandaStation `a72025a0480566585ab7cc48a62873581fe3a6a5`, локальная
BYOND 516.1688. Правила ниже описывают текущую игру Banda, а не Paradise.
Перенос архитектуры не даёт разрешения менять эти правила.

Это реестр требований и покрытия, а не заявление о готовности всего Rust-движка.
«Требует сценария» означает, что путь установлен по коду, но отдельного
автоматического игрового теста ещё нет. Численные микроскопические отклонения
регистрируются отдельно; изменение реакций, эффектов или игровых порогов
требует разбора с пользователем.

## Сохранённые исполняемые эталоны

| Набор | Что сохранено/проверяется | Ограничение |
| --- | --- | --- |
| `catalog.json`, `REACTIONS.md`, `compare.py` | Все 20 газов, 26 реакций, требования, формулы, RNG-ветви, порядок, флаги; 4405 сравнений с извлечённым оригинальным DM | Вместо настоящего мира в этом наборе регистрируются намерения вызовов |
| `transport-reference.json`, `transport.py` | Неизменяемые входы и результаты 17 именованных сценариев газообмена/тепла; дополнительно 240 генерируемых сравнений | Не включает полный планировщик, immutable-смеси, перенос через стены |
| `network-reference.json`, `network.py` | 12 сохранённых графов по 20 тиков; ещё 26 сравнений с исходным `process_cell` и группами | Обычные замкнутые графы; без космоса, стен, полного hotspot и движения предметов |
| `world-reference.json`, `world_behavior.py` | 14 сценариев в настоящей игре: вода, заморозка предметов/мобов, иммунитеты, очаги, повторная химия образца, `fire_act` | Стенд локальный, без игроков; не весь раунд |
| `cell.py` | Расчёт Rust и команды эффектов сверяются с записанными результатами настоящего мира | Это ещё не исполнение Rust-команд подключённым DM-сервером |
| `phase_world.py` | Настоящая DLL, исполнитель DM: 12 игровых сценариев, 10 графов по 20 тиков, 11 проверок очереди/времени жизни | По выбранному фазовому порядку; штатная обработка SSair в контролируемом стенде отключена |
| `world-feedback-reference.json` | Немедленное и отложенное влияние настоящего угля на газ через `fire_act` | Отдельный диагностический сценарий, не новый эталон допустимого поведения |

Команды `--record` создают эталон однократно и отказываются перезаписывать
существующий файл. Проверка использует исходные DM-процедуры; ожидаемые
результаты не подгоняются под Rust. JSON содержит входы, наблюдения, версию
BYOND и контрольные суммы исходников. Обновление эталона — отдельное
осознанное изменение поведения, а не способ сделать проверку зелёной.

## Запуск

```powershell
python tools/atmos/catalog.py --check
cargo test --manifest-path rust/atmos/Cargo.toml
python tools/atmos/compare.py --byond E:/Games/BYOND/bin
python tools/atmos/transport.py --byond E:/Games/BYOND/bin
python tools/atmos/network.py --byond E:/Games/BYOND/bin
python tools/atmos/cell.py
python tools/atmos/phase_world.py --byond E:/Games/BYOND/bin --name phase-next
python tools/atmos/world_behavior.py --byond E:/Games/BYOND/bin --name verify-next
```

В Windows сборке Rust нужен MSVC Developer Shell. Игровой стенд использует
отдельный каталог `tmp/atmos-world/<name>`, SQL отключён, bind — localhost.
Обычная сборка сервера этот стенд не включает. Проверки на production-версиях,
многотиковые сценарии мира, 50+ игроков и выигрыш инфраструктуры ещё впереди.
