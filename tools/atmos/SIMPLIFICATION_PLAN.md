# План упрощения Rust-атмоса

Дата: 2026-11-08. Ветка: `rust-atmos-pipes`.

Цель: уменьшить задержки главного потока и общий расход ресурсов относительно
исходного Banda DM. Ускорение собственного адаптера само по себе не считается
достижением цели. Реализация и измерения ведутся по одному изменению за этап.

## Ограничения

- Сохранять формулы, порядок газообмена, баланс газа, проверку наличия перед
  изъятием, версии привязок и уже выполненные операции при ошибке обработчика.
- Сохранять живые DM-ссылки и совместимый путь для сигналов и нестандартных смесей.
- При новой подтверждённой несовместимости сначала показать сценарий и варианты
  пользователю. Нельзя незаметно менять наблюдаемую свежесть газа или порядок эффектов.
- Не исправлять посторонние runtime. Не менять железо, affinity и общий MC.
- Не делать push/PR/deploy. Первый локальный checkpoint явно разрешён пользователем;
  последующие коммиты требуют отдельного запроса.
- Сохранять эталоны, проверки реакций и баланса, компактное хранение, AVX2,
  исправления жизненного цикла и прямую публикацию через BYOND C API.

## 4. Удалить исторические пути

- [ ] По фактическим потребителям убрать лишние форматы и capability probes
  промежуточных DLL. Предпочтителен один проверяемый контракт DM/DLL.
- [ ] Оставить необходимые fallback для живых смесей/сигналов/переопределений.
- [ ] Не приписывать очистке кода выигрыш CPU без отдельного измерения.

По результату этапа 3 массовое удаление fallback отложено: действующие проверки
совместимости DLL выполняются при запуске, их удаление не устраняет выявленные
публикацию и DM-эффекты. У старого конвейера уже удалены файл, include, очереди
и рабочие вызовы; осталось штатное перенаправление устаревшего config-параметра.
Следующее измерение должно сначала закрепить состав нагруженного мира.

## Критерий завершения

Тесты не показывают новых несогласованных отличий поведения; результаты повторов
показывают уменьшение длинных блокировок относительно checkpoint, а сравнение с DM
честно отражает оставшиеся CPU/RAM/TD. Если основным ограничением останется
целостная публикация, следующий этап выбирается по свежей трассе, без наращивания
конвейера на предположении.
