Сигнализации и анализаторы: чтение без выдачи газовой смеси.

База: e4b067b8c39, rust-atmos-api. Коммит/пуш этого этапа не запрошены.

1. Общий численный снимок тайла/порта: текущие моли с порядком ключей,
   температура, давление, объём, теплоёмкость, результаты реакций.
   Повторно использовать адреса протокола операций и query_air; чтение
   не материализует смесь, не делает порт exposed и не меняет состояние.
2. Независимый API показаний анализируемого объекта. Родной путь компонентов
   получает airs без return_analyzable_air(), который выдаёт живые ссылки.
   Собственные DM-смеси ещё не перенесённых ёмкостей читаются без новых копий
   газовых datums. Побочные эффекты их штатных провайдеров сохраняются.
3. Перевести ручной анализатор/atmos_scan, AtmoZphere, атмосферный компьютер
   и датчик, воздушную сигнализацию (события, UI, circuit). Сохранить состав
   UI-пакетов, порядок/нумерацию узлов, нулевые ключи, округление, диапазон,
   права и расход энергии. reference остаётся ключом UI, для воздуха Rust
   идентифицирует координату и версию привязки, не требует DM-смеси.
4. Для штатного обработчика check_danger не выдавать смесь в COMSIG_TURF_EXPOSE.
   Если другой слушатель требует живую смесь, сохранять существующий путь
   и читать именно переданный объект, включая его ещё не записанные правки.
5. Замороженные исходные DM-procs, Rust-тесты и игровые сравнения показаний,
   тревог, UI, датчика, схемы, неизвестного слушателя, версий, портов и aliases.
   Проверить отсутствие cached_air/readonly_air и сохранение native_owned.
6. Одинаковый стресс: пожар и плазма через трубы, активные сигнализации
   и чтение анализатором тайлов/портов. Два пути чтения, одна DLL/бинарник,
   фиксированная работа, MC/GC включены; свежие процессы, чередование,
   CPU всего/main/worker, ТД средний/пик, Private/RSS средняя/пик, число расчётов.
   Профайлер отдельно; выводы только после проверки равенства работы/состояний.

При подтверждённой новой несовместимости способ исправления согласуется
с пользователем. Трубные реакции/прочая физика и хранение контейнеров здесь
не переносятся; существующие побочные эффекты чтения ёмкостей не отменяются.

Согласовано пользователем: старое событие с air = null продолжает пропускаться.

показания тайла. Аргумент добавлен к тому же сигналу, порядок слушателей сохранён.
