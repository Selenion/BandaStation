# Контролируемый профиль границы DM/Rust

Цель: объяснить рост CPU/расчёт после упрощения. Производственные DM/Rust
не меняются; дополнительные hooks находятся только в диагностических снимках.

- [x] Собрать и проверить малый smoke: одинаковое состояние и объём работы.
- [x] Сравнить checkpoint c65fbacb60b, текущий цельный пакет и текущие порции.
- [x] Фиксировать конечную геометрию 64×64, порядок, выданные ссылки,
  число кадров, устройства и газ. Остановить фоновые подсистемы в стенде.
- [x] Порции в диагностическом снимке ограничить 128 группами команд тайла. Это тест затрат
  на одинаковом числе границ, не измерение ТД или скорости обычного MC.
- [x] Проверять итоговый газ, архив, порты, последовательность счётчиков мира
  и число выполненных команд. Различающиеся нагрузки не усреднять.
- [x] Три повтора без proc-профиля; один отдельный с профилем на каждый случай.
- [x] CPU/private/RSS снимать только с PID сервера, отдельно main и worker.
- [x] Разделить вложенные интервалы: копии, остальная публикация, эффекты,
  фиксация изменений, входные данные и устройства. Интервалы — время главного
  потока по монотонным часам; это не точный OS CPU каждого обработчика.
- [x] Сопоставить интервалы с self/total встроенного профайлера. Не складывать
  включающие друг друга времена и не подмешивать диагностический CPU в основной.
- [x] Сохранить сырьё, хеши, отклонённые попытки и ограничения вывода.

Проектируемые случаи: закрытая камера с пожаром; та же камера с одной сетью
и 64 вентиляциями, выпускающими плазму. Они изолируют границу DM/Rust,
не заменяют полную MetaStation, взрыв СМ или игровой раунд с 50+ игроками.

Текущая серия: `tmp/atmos-fixed-cost-03/`. Малый smoke совпал по начальному
и конечному газу, портам, trace, командам и выполненным кадрам; прямой путь
вентиляции подтверждён. Три теста счётчиков/интегрирования и gates прошли.
Предыдущие калибровки сохранены: v1 не выпускала плазму из-за давления;
v2 выдавала одинаковый газ, но использовала совместимый путь устройств.

В стенде загружается Minimal Runtime Station; фоновые подсистемы остановлены,
включая GC. Поэтому его RAM не используется для сравнения памяти рабочего
сервера. Эффекты включают настоящий world_commands с огнём и ветром,
субъекты — закреплённые огнестойкие гаечные ключи; работа мобов и прочих
подсистем не моделируется. Проценты нельзя переносить на весь игровой раунд.

Серия завершена: 24 принятых случая, 1920 расчётов, совпадающий объём работы
и сериализованные состояния, runtime нет. 22 Python-теста прошли.
[Отчёт](ATMOS_COST_REPORT.md) и [сводные данные](ATMOS_COST_RESULTS.json).

Причина новой регрессии: повторная сверка всего накопленного набора в DM.
На пожаре 2797568 посещений и 8392704 сравнения списков, при тех же 1024
вызовах DM-копирования. Цельный текущий пакет почти равен checkpoint;
порции увеличили CPU/расчёт до 835 против 370 мс на этом стенде.

Следующая реализация предложена, не выполнена: пакетная сверка live/read-only
через существующий Rust C API с прежними границами свежести и полным набором
проверок жизненного цикла. Квоту/планировщик рабочего сервера этот аудит не меняет.
